# photo.link

Мобильный сайт для публикации фотографий и получения прямых публичных ссылок. Интерфейс сделан на React + Vite, файлы загружаются в **Vercel Blob** через serverless endpoint.

## Подключение Vercel Blob

1. Импортируй репозиторий в Vercel.
2. В проекте Vercel открой **Storage → Blob → Create Store**.
3. Подключи Blob Store к проекту и выбери окружения `Production` и `Preview`.
4. Vercel автоматически добавит переменную `BLOB_READ_WRITE_TOKEN`.
5. Сделай redeploy.

Все загруженные изображения создаются с `access: "public"`, поэтому ссылка открывается у любого человека без авторизации.

## Локальная разработка

```bash
pnpm install
pnpm dev
```

Локальный Vite-превью показывает интерфейс. Для тестирования реальной загрузки нужен Vercel Blob token или локальный Vercel runtime.

## Ограничения

- Только изображения.
- Размер файла не ограничивается приложением; фактический предел может зависеть от лимитов Vercel Blob и выбранного тарифа.
- История ссылок хранится локально в браузере пользователя.
- Удаление фото пока не добавлено: публичные ссылки намеренно остаются доступными.
